# Roadmap

- **v0.2:** Near-duplicate / campaign clustering; evidence for precision and recall.
- **v0.3:** Compare a semantic classifier against frozen baseline; test warning negation.
- **v0.4:** Independent annotation guide, human disagreement analysis, FP/FN slices, drift tracking.
- **v0.5:** Local dashboard and audit export with deletion / retention controls.
- **v1.0:** Authentication, throttling, encryption, privacy review, human escalation, real-world benchmarking.

## Release gate
Never claim verified scam detection effectiveness from the bundled synthetic sample.
Do not deploy publicly without API security and lawful data governance.
